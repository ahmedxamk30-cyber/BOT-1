# DARK WA BOT PRO v7.0.1

نسخة مصححة من بنية المشروع المقدمة، مع الحفاظ على الفكرة العامة والملفات الأساسية.

## المتطلبات
- Node.js 20 أو أحدث
- npm
- اتصال إنترنت عند تثبيت الحزم وربط واتساب

## التشغيل
1. فك ضغط الملف.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ `npm install`.
4. انسخ `.env.example` إلى `.env` وراجع `OWNER_NUMBER` و`WA_PREFIX`.
5. شغّل `npm start`.
6. افتح `http://localhost:3000`.
7. امسح QR من واتساب > الأجهزة المرتبطة.

## مهم
- هذا المشروع يستخدم Baileys لجلسة واتساب عبر QR، وليس WhatsApp Cloud API الرسمية.
- `.ai` يستخدم واجهة xAI الفعلية إذا أُضيف `AI_API_KEY` صالح إلى `.env`.
- لا توجد أوامر افتراضية مزروعة في قاعدة البيانات؛ جدول الأوامر يبدأ فارغًا.
- لوحة الويب للعرض فقط في هذه النسخة. لم يتم تفعيل إضافة أوامر من المتصفح لأن تنفيذ كود من لوحة غير محمية قد يسمح بالسيطرة على الخادم.
- أوامر JavaScript المخصصة تستخدم `new Function()` كما في التصميم الأصلي. لا تضف أوامر من مصدر غير موثوق، ولا تعرض هذه الوظيفة للزوار.
- لا ترفع `.env` أو `sessions/` أو `dark_bot.db` إلى GitHub أو تشاركها.
- الاستضافة التي لا تسمح باتصالات WebSocket أو تخزين ملفات دائم قد لا تناسب جلسة Baileys.

## ملفات البيانات
- قاعدة البيانات: `dark_bot.db`
- جلسة واتساب: `sessions/`
- النسخ الاحتياطية: `backups/`

## التشخيص
إذا فشل تثبيت `better-sqlite3`، تأكد من استخدام إصدار Node.js LTS حديث ومتوافق مع نظام الاستضافة. قد يحتاج البناء من المصدر إلى أدوات بناء النظام.
